¿De dónde saco el código?
  1. Entra a github.com/settings/personal-access-tokens con la cuenta del sitio.
  2. Botón "Generate new token" → "Fine-grained token".
  3. Nombre: Panel Tu Colita. Vencimiento: 1 año. Anota la fecha.
  4. Repository access → Only select repositories → elige el repositorio del sitio.
  5. Permissions → Repository permissions → Contents → Read and write. Nada más.
  6. Generate token, copia el código y pégalo arriba. Solo se ve una vez.

Cómo funciona

Lo que editas queda guardado en el celular hasta que tocas "Publicar". Al publicar, la web real se actualiza sola en menos de un minuto.

Lo que más vas a usar: el interruptor de cada producto para marcarlo agotado. Un toque y publicar.

Recibir los contactos de la cortina
  1. Crea una hoja en sheets.google.com con estos títulos en la fila 1: fecha, contacto, tipo, origen, utm_source, utm_medium, utm_campaign.
  2. Menú Extensiones → Apps Script, pega el código que te pasaron con el sitio y guarda.
  3. Implementar → Nueva implementación → Aplicación web. Acceso: Cualquier persona.
  4. Copia la dirección que termina en /exec y pégala en la pestaña Apertura.
Si algo sale mal
  • "El código de conexión no sirve": se venció. Genera uno nuevo con los pasos de la pantalla de conexión.
  • "Alguien publicó desde otro lado": otro celular publicó mientras editabas. Elige recargar para ver lo último.
  • Se dañó la carta: usa "Restaurar respaldo" con el último archivo que descargaste.
  • La web no cambia: espera dos minutos y abre en una pestaña nueva.
